# TaskManager

A small deadline planner that runs entirely in the browser. No server or install needed.

**Live site:** https://arwashah.github.io/TaskManager/

## Features
- Task board with **To-do**, **In progress** and **Done** columns
- Add tasks with a title, course, CRN, date, duration and reminder
- Categories (Study, Personal, Clubs) plus custom titles with their own accent colours
- Everything is saved in your browser (localStorage), so tasks persist between visits

## Files
| File | Purpose |
|------|---------|
| `index.html` | The task board (home page) |
| `AddTask.html` | Form for adding a task |
| `taskboard.js` | Board and form logic, storage |
| `Study.css` | Styles for the planner |
| `todo.html`, `styles.css`, `script.js` | Earlier, unfinished to-do list prototype |

## Run locally
Download or clone the repo and open `index.html` in a browser.
